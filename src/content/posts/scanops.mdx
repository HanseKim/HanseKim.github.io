"PR만 올리면 자동으로 보안 취약점을 잡아주는 AI 보안 진단 서비스" ScanOps는 소스코드·웹사이트를 입력받아 OWASP ZAP 동적 스캔과 보안 특화 파인튜닝 LLM(QLoRA) + taint 그래프 분석으로 취약점을 탐지하고, CVE/CWE 매핑·CVSS 점수·한국어 수정 가이드를 자동 생성하는 웹 보안 진단 SaaS입니다. GitHub App을 레포에 설치하면 PR을 올릴 때마다 XSS·인젝션·SSRF 등을 분석해 해당 코드 줄에 댓글로 알려주고, 대시보드에서 스캔 기록·리포트·구독을 관리합니다.

## 🛠️ 기술 스택

- FrontEnd: React 19, TypeScript, Vite, Tailwind CSS v4, React Router v7, Recharts (FSD 아키텍처)
- BackEnd: Java 17, Spring Boot 3.2.5, Spring Data JPA, WebFlux, Spring Security + OAuth2, JWT
- AI 모델: Python, FastAPI, PyTorch, Transformers, PEFT(QLoRA), Qwen2.5-Coder (1.5B/3B/7B)
- 분석/DB: Taint 그래프(Neo4j) + Qdrant(벡터), sentence-transformers(bge-small-en), Ollama 서빙
- 인프라: Docker Compose, OWASP ZAP, DVWA, PostgreSQL, MariaDB
- 배포: Vercel(프론트), Railway(백엔드), AWS EC2(ZAP/모델)

## 💡 주요 기능

- DAST 웹 스캔: OWASP ZAP으로 실 사이트를 스캔해 취약점 탐지 (실 백엔드 연동)
- SAST 코드 스캔 + AI 분석: 파인튜닝 LLM + taint 그래프로 코드 취약점 탐지, CVE/CWE·CVSS·수정 코드 제시
- GitHub App PR 자동 분석: PR 시 자동 스캔 후 취약 코드 줄에 한국어 리뷰 댓글
- 스캔 결과 리포트 및 대시보드 (스캔 기록·취약점 아코디언·모델 성과)
- SaaS 구독 관리: GitHub OAuth 로그인, Free/Pro/Max 요금제·사용량 게이트

## 🧠 기술적 도전 & 성과

- '탐지율 100%'의 함정 발견 — 안전 코드를 취약으로 오판하는 오탐률(FPR)을 정적 mitigation 분석 + LLM 하이브리드 게이트로 100% → 6%로 개선
- 데이터 누수(OWASP 학습/평가 중복) 차단을 위해 OWASP를 학습에서 배제하고 CVEfixes(실제 2024 CVE)로 zero-shot 재평가 — 과적합 착시 제거
- OWASP 벤치마크: 그래프 하이브리드 F1 84.6, 재현율 100%, 정확도 81.8% (Grok-3 능가)
- v5 오탐 필터: 정확도 93%·F1 92.9 (Grok-3와 동등), 응답 약 10배 빠름
- 자체 호스팅 구독제(₩0 / Pro ₩49,000 / Max ₩149,000) 운영 가능
